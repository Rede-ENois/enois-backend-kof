# Kof gaps found while porting

Compiler/runtime issues hit by this project, measured on Kof 0.7.1 (JVM target). Each entry has a
minimal repro so it can be filed upstream on `KofLang/Kof4j`.

| # | Symptom | Repro | Workaround | Upstream |
|---|---|---|---|---|
| G1 | `db.execute`/`db.query` accept at most 4 bind params (`SEM025`), one shared connection | `db.execute(h, "insert into t values (?,?,?,?,?)", 1, 2, 3, 4, 5)` | `kernel.db` over HikariCP + JDBC | not filed |
| G2 | Java varargs call emits invalid bytecode: `VerifyError: String is not assignable to [Ljava/lang/String;` | `Flyway.configure().locations("filesystem:db")` | pass the array explicitly: `var a = new String[1]; a[0] = "filesystem:db"; cfg.locations(a)` works | not filed |
| G3 | Reading a public primitive field of a Java object emits invalid bytecode (`VerifyError: integer is not assignable to Object`) | `Int n = flyway.migrate().migrationsExecuted` | use getters / avoid the field | not filed |
| G4 | Overload resolution picks the wrong Java overload (`IncompatibleClassChangeError`) | `FluentConfiguration.configuration(HashMap)` dispatches to `configuration(Configuration)` | avoid overloaded APIs or use a non-overloaded entry point | not filed |
| G5 | `Map<K, Bool>.get` returns `Troolean`, not `Bool?` | `ps.setBoolean(1, m.get(k))` → `SEM014` | `m.get(k) == true` | by design? |
| G6 | `kof check` ignores `kofdeps` jars (`PKG006` on third-party imports) while `kof run --deps` resolves them | `import com.zaxxer.hikari.HikariConfig` + `kof check` | validate with `kof test`/`kof run --deps` | not filed |
| G7 | HTTP server answers `Connection: close` on every response (no keep-alive) | any `app.get` | none yet; measure under load before go-live | not filed |
| G8 | Generic methods are not parsed in classes (`PARSE018`), and a function type that mentions a type parameter is rejected (`SEM085`): no `Db.transaction<T>`, no `(Row) -> T` mapper | `class R { ident<T>(T x): T { return x } } and tx<T>(() -> T body): T { ... }` | `DbRow` snapshots + `List.map`; `db.transaction(() -> void)` with a captured result variable, plus `txLong/txStr/txBool` | not filed |
| G9 | `kof test` never sets an external classpath: any import of a kofdeps jar is `PKG006` (the kernel imports HikariCP/H2/Flyway) | `kof test --module-root src tests/ on a suite that reaches kernel.db` | `scripts/kof-test` (same flow as CmdTest through the compiler API, with the kofdeps jars) | not filed |
| G10 | `kof run src/Main.kf` with a `kof.toml` at the repo root resolves imports from the project root, so `import kernel.config` is `PKG006` (the sources live in `src/`); `[sources] app = "src"` does not help | `kof run src/Main.kf --deps` | `scripts/kof-run` | not filed |
| G11 | A Java method returning `String` called on an object whose class the resolver cannot read is typed `Object`: `NoSuchMethodError: ...SQLException.getSQLState()Ljava/lang/Object;`, `VerifyError` on `String` use. Hits `SQLException.getSQLState/getErrorCode`, `Socket`/`InputStream` chains (`ClassFormatError: Illegal class name ""`) | `var s = sqlException.getSQLState(); s.startsWith("23")` | classify SQL errors by message (`Db.isIntegrityMessage`); cast results `x as String`; assign chained calls to typed locals | not filed |
| G12 | A `throw` inside a `catch` block skips the `finally` of the same `try` (JVM): pooled connections leaked | `try { a() } catch (String e) { throw e } finally { release() }` | no `finally`: capture the failure, release, then rethrow after the try (see `Db.execute`) | not filed |
| G13 | The response header map is keyed by name: a second `headerSet("Set-Cookie", ...)` overwrites the first | `headerSet("Set-Cookie","a=1"); headerSet("Set-Cookie","b=2") sends only b=2` | `Cookies.add` sends each cookie under a case variant of the name (`Set-Cookie`, `set-Cookie`, ...), written as separate lines | not filed |
| G14 | The runtime does not expose the TCP peer address (`req.remoteAddr` is package-private), so a client IP needs reflection | `none in the stdlib` | `Req.peerAddress()` reads `KofRuntime.KOF_WEB_REQUEST.remoteAddr` by reflection | not filed |
| G15 | `kof.http` returns only the body: no status, no headers, no Set-Cookie; a 5xx throws and drops the body | `http.get(url) on a route answering 500 with a JSON error` | `kernel.testkit.TestClient` speaks HTTP/1.1 over a raw socket | not filed |
| G16 | `long`, `int`, `bool`, `double`, `fn` are reserved: they cannot name a method | `Long long(String c) { ... } -> PARSE018` | `getLong/getInt/getBool/getDouble`, `bindLong/...` | by design? |
| G17 | Stdlib builtins win over user members by name: an unqualified `query(...)` inside a class calls the web context function; a local called `db` captured in a lambda resolves to the stdlib `db` namespace (`unknown db connection: null`); an unqualified `transaction(...)` in a class method likewise | `class Db { queryList(...) { var r = query(sql) } }; var db = ...; run(() -> { db.execute(...) })` | call own methods with `this.`; never name a variable `db` (use `database`/`store`) | not filed |
| G18 | A function type with a nullable return (`() -> String?`) compiles but fails at runtime: `AbstractMethodError ... Function0_NCString` | `class F { () -> String? run } called after being built from () -> pass()` | filters return a `String` sentinel (`Http.next()`) instead of null | not filed |
| G19 | `x instanceof R` for a record `R` of the current package emits the unqualified class name (`NoClassDefFoundError`); a fully qualified Java type in a parameter (`ps: java.sql.PreparedStatement`) emits an empty class name | `v instanceof DbNullBind inside package kernel.db` | parallel `nullTypes` list instead of instanceof; import the Java type and use the simple name | not filed |
| G20 | After `if (v == null) { f() } else { g(v as Object) }` with a nullable parameter the bytecode has a bad stack map (`VerifyError`); same for a `Double?` parameter | `DbParams bindLongOrNull(v: Long?) { if (v == null) { addNull() } else { addValue(v as Object) } return this }` | early `return this` in the null branch; no `Double?` parameter | not filed |
| G21 | More wrong-overload picks: `Timestamp.valueOf(LocalDateTime)` -> `valueOf(String)`; `LocalDate.now(ZoneOffset.UTC)` -> `now(Clock)`; `ObjectMapper.readTree(String)` -> `readTree(JsonParser)`; `ZonedDateTime.plusSeconds(1)` needs `1L` | `see names` | use `Instant`/`toString()` arithmetic; `kernel.testkit.JsonPath` instead of Jackson trees | not filed |
| G22 | `String.getBytes("UTF-8")` does not resolve (only the no-arg form); `String.split` returns an array (`.length`, `a[i]`, regex argument: `split("\\.")`); `Map<String,List<String>>.get` cast to `List<String>` throws `ClassCastException` on JDK unmodifiable lists | `"x".getBytes("UTF-8")` | use `getBytes()` (UTF-8 default on JDK 18+); iterate `HttpURLConnection` headers by index | not filed |
| G23 | No top-level variables (`String X = "a"` -> `PARSE011`); `assert(cond, msg)` needs a literal message (`PARSE087`); a lambda whose body only throws cannot be typed (`SEM014`); `Bool?` is `SEM095` | `String NEXT = "x"` | constants as functions; `Check.*` helpers with dynamic messages; `String f() { throw ... }` as the handler body | by design? |
| G24 | Nested Java classes cannot be imported (`java.net.http.HttpResponse.BodyHandlers`, `...$BodyHandlers`) | `import java.net.http.HttpRequest.BodyPublishers` | avoid APIs that need them (`java.net.http.HttpClient`) | not filed |
| G25 | Thrown values must be Strings (`SEM026`); a class extending `RuntimeException` has no `getMessage` (`SEM025`). `catch (String e)` also catches every Java exception (its message) | `throw ApiErr(404, "X", "m")` | `ApiException` travels as a tagged String (`Errors.api`), decoded by `Errors.parse` | by design |
| G26 | Top-level function names are one flat namespace across packages (`SEM047` for the same name in two packages); static class members are the only namespace | `two packages each declaring String same()` | `class` with `static` members (`Config`, `Time`, `Req`, ...) | by design? |
| G27 | The web runtime adds hardening headers (CSP, nosniff, X-Frame-Options, Referrer-Policy) to every route response even without `app.security()` | `any app.get response` | left as is; the security task decides what to keep (`SecurityHeadersFilter` parity) | not filed |
